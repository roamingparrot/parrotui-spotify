# Keybindings

| Key          | Action                  |
|--------------|-------------------------|
| `j` / `↓`   | Move down               |
| `k` / `↑`   | Move up                 |
| `h` / `←`   | Collapse / go back      |
| `l` / `→` / `Enter` | Expand / select |
| `gg`         | Jump to top             |
| `G`          | Jump to bottom          |
| `Space`      | Play/pause              |
| `n`          | Next track              |
| `p`          | Previous track          |
| `+` / `-`    | Volume up/down          |
| `s`          | Toggle shuffle          |
| `r`          | Cycle repeat mode       |
| `>` / `<`    | Seek forward/back 5s    |
| `?`          | Show help               |
| `q`          | Quit                    |
| `Tab`        | Switch focus panel      |
